    What ChordForge is

    ChordForge is a free chord progression generator that writes the MIDI for you.

    You pick a key, a scale and a mood. It builds a progression that stays in that key, adds a four-note guide melody over every chord, and exports both as a standard multi-track .mid file you can drag into any DAW. It runs entirely in your browser: no account, no upload, nothing kept on a server.

    It is built for the moment before a track exists. Instead of staring at an empty arrangement you get four bars of harmony to react to, with the roman numeral printed under each chord so you can see why the loop works and repeat the trick without the tool.

    How to use it

    1. Pick a key on the keyboard strip, then Major or Minor. Every chord after this is built from that scale.
    2. Choose a mood. Dreamy, Dark, Epic, Lo-fi, Sad, Uplifting and Jazzy each draw from their own set of chord shapes.
    3. Set the tempo. The slider runs 60 to 180 BPM and the value is written into the exported file.
    4. Press Generate. Four chords appear with their symbols and roman numerals. Regenerate gives you a different progression at the same settings.
    5. Press Play to hear it loop. The chord that is currently sounding lights up, so you can hear which one you want to keep.
    6. Press Export .mid. You get one file with two tracks: the chords, and the guide melody over the top.
    7. Drag that file into your DAW and point it at any instrument. Nothing else to install.

    Share copies a link that rebuilds the exact progression you are looking at, which is the fastest way to send an idea to whoever you are writing with.

    Works with your DAW

    The export is a plain multi-track MIDI file, so anything that reads MIDI will open it. What each DAW does when you drop it in:

    Ableton Live
    Drag the file into Session or Arrangement view. Live creates one MIDI track per track in the file, so the chords and the melody land separately and can go to different instruments.
    FL Studio
    Drag it into the Playlist, or use File → Import → MIDI file. FL asks how you want the tracks laid out, then puts each one on its own channel.
    Logic Pro
    Drop it on an empty part of the Tracks area. Logic makes a software instrument track per MIDI track and offers to take the tempo from the file.
    Reaper
    Drag it into the track panel. Reaper asks whether to expand the file into separate tracks or keep it as one item; separate keeps the melody editable on its own.
    Bitwig Studio
    Drag it onto the arranger for a clip per track, or drop it straight onto an existing instrument track to hear it through that device immediately.
    GarageBand
    On the Mac, drag the file into the timeline and it becomes software instrument regions. GarageBand for iPhone and iPad cannot import MIDI files, so use the Mac version or another iOS app that accepts them.

    Chord progressions by mood

    Each mood is a small pool of templates written in scale degrees, so the same shape gives you different chords in every key. Here is one template from each mood, with the chords it produces in a common key. The numerals are exactly what the tool prints under the chips.

    Dreamy

    I–iii–IV–vi

    C major: C · Em · F · Am

    It never touches the dominant, so nothing pulls hard toward home. The loop drifts between the tonic and its relative minor, which is why it sits under a pad without ever demanding a resolution.

    Sad

    i–VI–III–VII

    A minor: Am · F · C · G

    Three major chords orbiting one minor chord. The minor tonic sets the mood, but everything around it is bright, and that mix is what reads as wistful rather than grim.

    Dark

    i–♭VI–♭VII–i

    A minor: Am · F · G · Am

    The same family as the sad loop with the third chord cut and the tonic returning early. Landing back on the minor chord every four bars is what keeps the weight on the floor.

    Lo-fi

    i7–iv7–♭VII–III

    A minor: Am7 · Dm7 · G · C

    Sevenths soften both minor chords into jazz territory. The last two are a straight V–I into the relative major, so the loop brightens for a bar before it drops back to the top.

    Uplifting

    I–V–vi–IV

    C major: C · G · Am · F

    The four chords behind the famous medley. It leaves home on the dominant, dips into the relative minor, then walks back through the subdominant. Epic is the same four rotated to start on vi, which delays the tonic and makes the arrival bigger.

    Jazzy

    ii7–V7–Imaj7–Imaj7

    C major: Dm7 · G7 · Cmaj7 · Cmaj7

    The ii–V–I, the sentence most jazz standards are built from. The tritone inside G7, between B and F, is the tension; it resolves into Cmaj7, which then holds for a second bar.

    Flat numerals mark chords borrowed from the parallel minor. In a minor key they are already diatonic; in a major key they are the color.

    Do I need an account?
    No. There is no signup and no login. Everything runs in your browser and nothing you generate is uploaded. Saved progressions and the Pro unlock live in your browser's local storage, so they stay on the device you used.
    What is a MIDI file?
    A MIDI file holds notes rather than sound: which pitch, when it starts, how long it lasts and how hard it was hit. Your DAW plays those notes through whichever instrument you point them at, so the same .mid can be a piano, a pad or a bass. It also stays fully editable, so you can move or delete any chord after importing it.
    How do I import a MIDI file into my DAW?
    In almost every DAW you drag the .mid out of your downloads folder and drop it into the arrangement or playlist. The DAW notes above cover the exact behavior in Ableton Live, FL Studio, Logic Pro, Reaper, Bitwig Studio and GarageBand.
    Can I use these chord progressions in music I sell?
    Yes. A chord progression on its own is not copyrightable: copyright protects a specific recorded or written work, not the underlying sequence of chords, which is why the same four chords turn up in hundreds of released songs. Whatever you write on top of one is yours. No attribution, no royalties, no license to buy.
    Does ChordForge work on a phone?
    Yes. The layout is built for a phone screen first, and playback works in mobile browsers once you tap Play, because browsers require a tap before any audio can start. Exported files go wherever your phone saves downloads, which on iOS is the Files app.
